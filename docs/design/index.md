# seams design

The `docs/design/` folder holds the canon for seams and the maintained overviews of its current design.
Canon is the set of statements the operator has accepted, and only the operator accepts changes to it.
Agents propose changes through a proposal in `.agents/proposals/`.

- [vision.md](vision.md) says what seams is for and what it doesn't try to do.
- [principles.md](principles.md) says how seams decides between options.
- [invariants.md](invariants.md) lists the rules that every project using seams keeps.
- [overviews/](overviews/index.md) holds maintained descriptions of the current design for maintainers.

The [guide](../guide.md) explains how these pieces work together in a project.
